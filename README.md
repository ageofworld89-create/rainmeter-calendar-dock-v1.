# Rainmeter Calendar Widget

Виджет-календарь для Rainmeter.

## Файлы
- `Calendar.ini` — скин и верстка
- `Calendar.lua` — логика на Lua

## Запуск
1. Кинь папку с файлами в `Документы\Rainmeter\Skins\<Имя_папки>\`
2. В трее кликни по Rainmeter ПКМ -> **Обновить всё**
3. В окне управления выбери `Calendar.ini` и жми **Загрузить**
